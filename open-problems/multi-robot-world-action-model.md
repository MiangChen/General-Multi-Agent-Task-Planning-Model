# 多机器人 World Action Model

现有 WAM 主要建模单机器人动作和世界视频变化。多机器人任务规划需要联合动作世界模型。

## 研究问题

- 多机器人联合动作空间如何表示。
- 模型是否需要显式 robot token 和 object token。
- 通信动作、等待动作、避让动作是否应纳入 action model。
- 预测目标应是视频、状态图，还是两者结合。
